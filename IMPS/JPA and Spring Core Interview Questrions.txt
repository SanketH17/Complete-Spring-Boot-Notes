🧩 Scenario-Based JPA Interview Questions
Entity Relationships

Scenario: You have User and Order entities. A user can place multiple orders. How would you model this relationship using JPA annotations?

Follow-up: What happens if you delete a user? How do you handle cascading deletes?

Lazy vs Eager Loading

Scenario: You notice performance issues due to unnecessary data fetching. How would you optimize entity loading?

Follow-up: How do you prevent LazyInitializationException in a web application?

Custom Queries

Scenario: You need a query to fetch all users who placed orders worth more than ₹10,000 in the last month. How would you write this using JPQL or native SQL?

Optimistic vs Pessimistic Locking

Scenario: Two users try to update the same bank account balance simultaneously. How would you ensure data consistency?

Inheritance Mapping

Scenario: You have a base class Vehicle and subclasses Car and Bike. How would you map this hierarchy in JPA?

Auditing

Scenario: You need to track who created or updated an entity and when. How would you implement auditing in JPA?
